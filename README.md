# Phoenix

Пример приложения [Phoenix](https://www.phoenixframework.org/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `4000` |
| Путь проверки состояния | `/` |

Railpack видит `mix.exs`: ставит Erlang и Elixir, зависимости, собирает статику
(`mix assets.deploy`) и релиз (`mix release`) и запускает его. Сервер слушает порт из переменной
окружения `PORT` — её передаёт платформа, — а без неё `4000`. Первая сборка идёт около 12 минут:
Erlang собирается из исходников.

На вкладке «Переменные» задайте:

| Переменная | Значение |
| --- | --- |
| `PHX_HOST` | домен приложения, например `app.example.com`; без него не подключаются LiveView и каналы |
| `SECRET_KEY_BASE` | ключ из `mix phx.gen.secret`; без него ключ создаётся заново при каждом запуске, и сессии сбрасываются |

В демо нет `mix.lock`: версии пакетов выбираются при сборке по требованиям из `mix.exs`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
mix setup

# запуск приложения
mix phx.server
```
